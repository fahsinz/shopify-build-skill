# shopify-build

A Claude Code skill: sequential, resumable workflow for building a Shopify store (theme, store data, operations) from a brief.

## Install

Clone into your skills folder:

```
git clone <this-repo-url> ~/.claude/skills/shopify-build
```

Then in a project folder, run `claude --chrome` and type `/shopify-build`.

Requires the Shopify CLI and Claude in Chrome. See `SKILL.md` for details.
